# 공구 크리에이터 담기 (크롬 확장 프로그램)

인스타그램 프로필 화면에 **＋ 공구 허브에 담기** 버튼을 띄웁니다.
누르면 공구 허브의 크리에이터 등록 화면이 정보가 채워진 채로 새 탭에 열립니다.

## 설치

1. 이 폴더를 컴퓨터에 압축 풀어둡니다 (아무 데나 두되, **나중에 지우면 안 됩니다**)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택
5. 주소창 오른쪽 퍼즐 아이콘 → 이 확장 프로그램 클릭 → **공구 허브 주소** 입력 후 저장

## 쓰는 법

인스타그램에서 크리에이터 프로필을 열고, 팔로우 버튼 옆의
**＋ 공구 허브에 담기** 를 누릅니다.

## 무엇을 가져가나

지금 열려 있는 프로필 화면에 **보이는 것만** 가져갑니다 — 이름, 아이디,
팔로워 수, 소개글, 프로필 사진 주소. 버튼을 누른 그 한 명분만입니다.

인스타그램에 로그인 정보를 넘기거나, 자동으로 돌아다니며 수집하지 않습니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 기본 정보 |
| `content.js` | 인스타 화면에 버튼을 넣고, 눌렀을 때 정보를 모아 보냄 |
| `content.css` | 버튼 모양 |
| `options.html` / `options.js` | 공구 허브 주소를 저장하는 설정 화면 |
